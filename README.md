# FORJA — Gym Landing Page

A bilingual landing page concept for a CrossFit and martial arts gym. FORJA combines a dark visual style with discipline cards, membership plans, a calorie estimator, and a simulated first-class booking flow.

> **Portfolio demo:** FORJA is a fictional gym. Prices, testimonials, availability, contact details, and other business claims are sample content. The booking form runs entirely in the browser: it does not send data, reserve a real class, or process payments.

## Features

- EN/ES switch for page content, plans, calculator labels, and booking flow.
- Responsive navigation, animated hero, discipline and plan cards, and mobile call to action.
- Calorie estimator based on weight, session length, intensity, and discipline. Results are illustrative estimates, not medical or fitness advice.
- Demo booking dialog for a discipline, date, and time, followed by a local confirmation.
- Consistent outlined SVG icons in place of emoji.
- Motion effects with reduced-motion styling.

## Run locally

No package manager or build step is required.

```bash
git clone https://github.com/carlos2024r3223rw/Gym-landing-page.git
cd Gym-landing-page
```

Open `index.html` in a browser or serve the folder with a static server.

## Customize

- Edit `CONFIG` in `script.js` for disciplines, plans, sample testimonials, and calorie estimator values.
- Keep the matching English entries in `EN_TEXT` up to date when changing Spanish text.
- Update example contact details in `index.html` before adapting the concept for a real business.
